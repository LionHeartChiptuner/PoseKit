PoseKit Editor

I'm not exactly good with README's, but I'll give it a go.

On launch, the mod opens a local server and hosts the app. The server can be quickly accessed by going to custom buttons. In order to use it, you must load the hand rig first.
This editor allows for full hand poses for GlovesTan3 by JerryAr. Gun models are streamed directly from the running game.

This mod is not quite as fleshed out as I want it to be, but it's got enough to release.

Contributing

I've created a GitHub Repo at https://github.com/LionHeartChiptuner/PoseKit-Poses for uploading community poses, please send your creations!
