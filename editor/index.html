Workflow

  1. Install the PoseKit plugin next to GlovesTan3.
  2. In game, spawn the gloves, hold the gun and press PoseKit: Capture L/R (or F5/F6).
  3. Import the capture from BepInEx/config/GlovesTan3Poses/captures.
  4. Refine each slot here, then Export for game into BepInEx/config/GlovesTan3Poses.
  5. Press PoseKit: Rescan Folders (F7) and grab the gun again.
